NaTT XML format

sym
    • <sym>
      • text
      </sym>
term
    • sym constant or variable
    • <app>
      • sym function
      • term+ arguments
      </app>
cond
    • <cond> conditions for conditional rules
      • term
      • term
      </cond>
rule
    • <rule>
      • term left hand side
      • term right hand side
      • cond* conditions
      </rule>
sym-decl
    • <var> declares a variable symbol
      • text
      </var>
    • <fun> declares a function symbol
      • arity="[0-9]+"
      • (theory="AC?|C")?
      • text
      </fun>
root
    • <trs>
      • sym-decl*
      • rule+
      </trs>
